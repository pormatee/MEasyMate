# MEasyMate Customer Web Content Standard V1

Customer-facing pages should answer:
1. What does this tool help with?
2. Who is it for?
3. What are the key features?
4. Is it free, trial, launch promotion, or still developing?
5. What happens to the user's data?
6. How can the user start or contact MEasyMate?

Keep these internal unless needed for a user decision:
- RC / framework / frozen / PASS labels
- Source of Truth / repo / schema / architecture
- Evidence IDs / implementation evidence
- release gate / retrofit / regression / QA internals
- fail-closed terminology
- research backlog / next iteration / engineering roadmap
- internal version numbers that do not help the customer

Brand direction:
- Local-first
- No-server by default where possible
- Use Network only when necessary
- Personal data stays with the user as much as possible
- Mobile-first and easy to use
