คำถามที่พบบ่อย

Q
Local Product ต้องต่อ Internet ตลอดไหม?

ไม่จำเป็นสำหรับ Core Function ของ Product ที่ระบุว่า Offline-first; Internet อาจใช้สำหรับ License, Update, Notice หรือ Download ตามความจำเป็น

Q
ข้อมูล Report/Factory ถูกส่งกลับ MEasyMate หรือไม่?

Local Product ถูกออกแบบให้ข้อมูลการทำงานหลักอยู่ในอุปกรณ์ของผู้ใช้ ไม่ส่งกลับ MEasyMate โดยอัตโนมัติ

Q
ถ้า Product มีปัญหาควรทำอย่างไร?

ดู Version และ Release Notes ก่อน หากยังแก้ไม่ได้ ติดต่อ LINE Official พร้อมชื่อ Product, Version และอาการที่พบ โดยไม่ส่งข้อมูลลับที่ไม่จำเป็น
