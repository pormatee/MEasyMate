# MEasyMate

**Make Everything Easy**

MEasyMate is an AI & Digital Tools Ecosystem designed to make work and everyday life easier.

## Ecosystem
- AI
- Work
- Life
- Growth

## Product principles
- Easy to Use
- Mobile First
- Privacy First
- Offline First where appropriate
- Local-first customer data for local products
- Clear product status: no unfinished concept is presented as ready for sale

## Branch workflow
- `main` — stable / production-ready
- `dev-v2` — current development and UX validation

Development flow: `dev-v2 → Android test → review → main`

Do not push experimental work directly to `main`.
